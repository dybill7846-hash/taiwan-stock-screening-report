# taiwan-stock-screening-report
台股四海遊龍每日完整報告｜僅公開報告，分析程式及歷史資料保留於私人專案。

[閱讀最新成功報告](https://dybill7846-hash.github.io/taiwan-stock-screening-report/)

每日成功分析後覆蓋同一網頁，請以頁面標示的分析交易日為準。休市或分析／部署失敗時，保留上次成功報告，不將舊資料標示為今天。

網站只發布完整報告及其驗證資訊，可免登入閱讀並下載 Markdown。此公開倉庫的 Git 歷史仍會保存過去報告；不包含私人程式、歷史資料庫、LINE 金鑰或收件者資訊。

報告為依固定規則產生的技術分析參考，不保證報酬，亦不會代替使用者下單。
